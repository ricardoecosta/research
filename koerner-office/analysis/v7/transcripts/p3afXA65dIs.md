## Tactics and playbook steps

**Install Higgsfield plugin in ChatGPT and generate an ad from a product photo** (product)
1. Install the Higgsfield plugin via the link, click add to plugin, log into ChatGPT, install and allow
2. Select Astra model
3. Attach the product photo (background removal is automatic)
4. Prompt: make a high energy ad for the product using Higgsfield, with campaign name
5. Specify the video model (e.g. Seedance 2.5) if the default output is poor
> "if you want something specific such as sea dance, cling, v3, whatever you want, make sure you type it in on the chat window" — George McConnell (~2:51)

**Lock a reusable AI character** (product)
1. Describe the persona (age, vibe, hair, makeup)
2. Ask ChatGPT with Higgsfield to write a detailed identity prompt covering bone structure, eyes, eyebrows, nose, mouth, teeth
3. Generate the character in Higgsfield
4. Rename the character and reuse by name
5. Attach product reference and instruct not to alter face, hair or build

**Make AI stills look like real UGC** (product)
1. Generate the stills first
2. Then ask for more realistic natural photos with different clothing in each, phone camera quality, slightly imperfect framing, real room clutter
3. Apply this request after generation rather than before to avoid confusing the model
> "always save it for after" — George McConnell (~13:16)

**Hook-variant testing across platforms** (acquisition)
1. Generate a 20s UGC video, choose the best
2. Request three alternative openers for the first two seconds (question, hot take, product theme)
3. Post all on TikTok
4. Move the winning video to Instagram and Facebook

**Recover from safety-filter false flag** (operations)
1. If a prompt is flagged not safe for work, credits are refunded
2. Rerun adding context about what people are wearing

## Lessons

- *automation_ai*: Name a reusable AI character and attach the product reference every time to keep identity and product consistent across assets.
- *offer_design*: Ask for realism fixes (clutter, imperfect framing, varied outfits) after the first generation to make AI imagery pass as UGC.
- *validation_testing*: Test several hooks on one platform before pushing the winner to others; cheap AI generation makes this affordable.
- *automation_ai*: Choose the video model per task; short prompts suit Seedance, longer detailed prompts suit director-style ads.
- *customer_acquisition*: A single ad is not enough: shoppers who see an ad will look up the brand, so profile content with a face and lifestyle imagery matters.
- *operations*: Plan for rate limits and false content flags when building agent workflows on top of generation tools.

## Warnings and mistakes

- Safety filter may falsely flag prompts as not safe for work; add clothing context and rerun.
- Rate limits on lower Higgsfield plans can block generations.
- AI images may look obviously AI (empty streets, same outfit) and need realism prompting.
- Cling does poorly with short prompts and produced a static image with an odd overlay.
