## Lessons

- *finance_unit_economics*: Pay-per-use APIs beat subscriptions when usage is uneven, and let you compute exact cost per deliverable.
- *automation_ai*: Plug media-generation APIs into your existing agent rather than using each tool's web UI.
- *finance_unit_economics*: Compare per-second model prices across providers (Higgsfield vs fal) before committing.
- *operations*: Keep API keys tied to a billing balance and track daily burn.

## Warnings and mistakes

- Subscription users often leave paid credits unused.
- Every generation immediately draws down your balance; monitor spend.
- Video is promotional, with a referral/sign-up link and time-limited discount.
