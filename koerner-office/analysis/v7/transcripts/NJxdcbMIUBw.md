## Tactics and playbook steps

**Katana 'mentality' video from five photos** (product)
1. Install the Higgsfield connector into Claude
2. Type /katana and pick a template
3. Upload five photos: standing, neutral face, serious face, three-quarters, side
4. Optionally add no text and let it generate the full music video
> "click install Higsfield into Claude. This is going to say, "Hey, add a custom connector." Click continue, hit approve" — George McConnell (~0:21)

**Iterate on weak first renders** (product)
1. Ask for a campaign film for the product
2. If basic, request specifics: target age, quick cuts, in-your-face motion
3. Edit out over-stylised parts afterwards
> "I said, I need something that's going to be powerful. I want something that has a lot of quick cuts" — George McConnell (~3:54)

**Reuse chat context for follow-ups** (operations)
1. Keep the product's photos and context in the same chat
2. Send a two-word follow-up like 'Katana launch cut'
3. Get a 30-second launch video without new prompting
> "I didn't need to give it any more context because it already had all the context" — George McConnell (~8:37)

## Lessons

- *automation_ai*: Template-driven AI video reduces prompting effort and credit waste.
- *finance_unit_economics*: Check credit estimates and hard caps before running generation jobs.
- *automation_ai*: Keep context in one conversation so follow-up assets need minimal instructions.
- *operations*: Avoid mixing your own footage into AI-generated faceless scenes unless all scenes feature you.

## Warnings and mistakes

- Too many people in generated scenes, or mixing real self-footage, makes faceless videos look unnatural.
- First outputs can be basic; budget credits for re-renders.
- Video promotes an affiliate link and a gated 'master list' of commands.
