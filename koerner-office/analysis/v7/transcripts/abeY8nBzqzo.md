Chris Koerner interviews a Dubai-based builder (name not stated in the transcript) who uses AI coding tools (Cursor, Claude Code) to build programmatic-SEO directory sites. ### I1. Guilty Chef - restaurant-inspired recipe programmatic SEO site

- **Customer:** Home cooks searching for copycat recipes of restaurant dishes (for example Wagamama or Wingstop).
- **Problem:** No single aggregated site for restaurant-inspired recipes; existing ones are individual home cooks' blogs.
- **Offer:** Pages of restaurant dishes and recipes, plus a paid section where users generate their own recipes (Anthropic API in the background).
- **Business model:** Organic SEO traffic converting to a low-priced paid membership (about $5) for a recipe generator; no ads yet.

- **Acquisition:** seo_organic_search: Programmatic SEO pages per restaurant and dish with schema.org markup, internal links and AI-written content; zero paid ads; rebuilt around June, Google traffic rose from about August 2024. Also surfaces as a source in ChatGPT.

- **Risks:** AI-generated content and Google algorithm changes; Using restaurant brand names in recipe pages; Revenue is small and rests on a few SEO keywords; Delayed SEO feedback of about 5 months
- **Automation [E]:** acquisition 4/5 (SEO page generation and publishing can be agent-driven, with occasional human strategy checks.); onboarding 5/5 (Self-serve signup.); delivery 4/5 (AI generates the recipes and pages; occasional bug fixes needed (he notes bugs he has not looked at for months).); billing 5/5 (Subscription via standard payment processing.); support 4/5 (Low support load; a support agent can handle it.)

## Tactics and playbook steps

**Keyword-first niche selection with Ahrefs** (acquisition)
1. Use Ahrefs Keywords Explorer with a broad seed keyword
2. Filter for keyword difficulty 0-30
3. Prefer higher search volume (over 1,000 is good)
4. Check that long-tail variants exist and will aggregate traffic
5. Find the closest .com on Instant Domain Search
> "you want to keyword difficulty between zero and 30" — Guest (~19:30)

**Programmatic SEO with schema markup** (product)
1. Create a category (for example restaurants) with Cursor/Claude and ask for schema.org properties
2. Generate content pages with AI
3. Interlink pages
4. Publish thousands of pages and be patient for several months
> "creating content, linking between the pages of your content, you know, using schema" — Guest (~5:05)

**Cursor writes prompts for Claude Code, with Firecrawl research** (operations)
1. Ask Cursor to research the market with Firecrawl without executing
2. Have Cursor write the Claude Code prompt
3. Paste it into Claude Code to build
4. Return Claude's feedback to Cursor
5. Make micro-iterations directly in Claude Code
> "the most valuable way to use AI is to get the AI to talk to the AI" — Guest (~64:25)

**Design inspiration folder** (product)
1. Browse Dribbble (including /buckets) for designs
2. Save an image to a design reference folder in the project
3. Tell Claude Code to apply the style to the page

**Clone a project to launch new niche sites** (operations)
1. Duplicate the project folder
2. Rename it for the new niche
3. Swap branding and images
4. Regenerate content and database data

## Lessons

- *mindset_execution*: SEO needs patience; pages can sit for months before Google rewards them, and the cost of waiting is low.
- *pricing*: Low-price subscriptions from high-traffic pages add up, since many buyers pay and then go inactive.
- *niche_selection*: Low-difficulty, high-volume keywords with a long tail of variants are the core filter for picking a niche.
- *niche_selection*: Domain name matters less than structure and content for ranking, but an exact-match .com is a bonus.
- *validation_testing*: Test ideas by building them rather than debating; AI cuts execution costs enough to get factual answers quickly.
- *automation_ai*: Skills with AI coding tools are valuable for services as well as products; large project fees are possible.
- *mindset_execution*: A wrapper app may become obsolete, but building it teaches skills and momentum; many opportunities last longer than feared.
- *niche_selection*: Large companies skip niches that are too small for them, leaving lanes for small builders.

## Warnings and mistakes

- Giving the AI too many tasks at once makes it trip up; compartmentalise tasks.
- SEO gives no feedback for months; a persistent build is needed (Google responded after about 5 months).
- AI output has bugs and the knowledge cutoff dates content (it suggested 'best protein snacks 2024').
