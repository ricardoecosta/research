## Tactics and playbook steps

**Set up a managed OpenClaw server and Telegram bot** (operations)
1. Choose Managed OpenClaw on Hostinger and enable Instant Web Search.
2. Connect an Anthropic API key, or consider the optional ready-to-use key add-on described in the video.
3. Choose Telegram, create a bot through BotFather, paste its token into the setup, and approve the matching connection code.
4. Test the agent by asking it to research a topic.
> "I'm gonna choose Telegram because I already use it for other stuff. Okay, you can use Telegram on your desktop or on your phone." — Chris Koerner (~3:16)

**Use a specific research prompt** (product)
1. Define the agent as a trend research assistant for approachable small-business ideas.
2. Ask it to search the web for the top three trending ideas and stories.
3. Request one-sentence summaries, one content angle, and a clean numbered list.
4. Tailor the prompt to the subject area; the host suggests adding home-service ideas.
> "When I ask for ideas, search the web for the top three trending novel and approachable business ideas and stories of people that are building cool products or services for each topic right a one sentence summary and suggest one content angle I can post about today send it as a clean numbered list." — Chris Koerner (~4:40)

**Troubleshoot web search by changing skills** (operations)
1. When the initial web search fails, open the skills area.
2. Search ClawHub for web_search and web_fetch and install them.
3. Turn off browser automation, return to chat, and retry the prompt.
> "I'm gonna search under claw hub, web underscore search, and then I'm gonna install that, okay? This will just make this work more cleanly than that, and then I'm also gonna search web underscore fetch." — Chris Koerner (~6:24)

**Personalize the agent to the creator** (product)
1. Upload transcripts from earlier episodes so the agent can learn the creator's preferred words and vocal patterns.
> "I would train this agent on my content, on my voice. I would upload transcripts from previous episodes so it knows what words I like to say, how I talk my vocal patterns, et cetera." — Chris Koerner (~8:03)

**Turn on proactive trend alerts** (operations)
1. Connect the agent to other tools such as Zapier or Gmail.
2. Use Twilio if the preferred alert is a text or call.
3. Set the agent to notify the owner when a relevant business idea or story appears.
> "So it could text me or call me or whatever I prefer any time, a new, crazy, incredible business idea or story drops that might be relevant to the type of content I post about." — Chris Koerner (~8:28)

**Choose a model for cost and capability** (product)
1. Check which model the installation selected by default.
2. Compare the default Haiku model with a more capable model for the intended task.
3. Account for API-key costs; the video does not state model usage prices.
> "It's using haiku, which is a fairly cheap and somewhat old, at least the AR world is kind of old. Claude or anthropic model, I would prefer it uses Opus 4.7, which is the newest and pretty incredible." — Chris Koerner (~5:34)

**Reuse the hosted setup as a starting point for an agency** (scaling)

## Lessons

- *customer_acquisition*: Being early can draw more attention, but the view-count comparison is an illustrative claim rather than demonstrated performance.
- *automation_ai*: A managed server can keep an agent running when the owner's laptop is closed.
- *operations*: Test an agent's tools in practice; a web-search capability may need additional skills and configuration.
- *offer_design*: A generic prompt can produce generic results; tailor the task to the creator's niche and needs.
- *automation_ai*: Use the creator's previous work as context when the agent needs to match their voice.
- *automation_ai*: An on-demand research assistant is less useful than a system that alerts its owner when relevant stories appear.
- *validation_testing*: Keep a human involved in assessing research before publishing; the host says the initial results were not much better than ordinary searches.
- *mindset_execution*: The host values speed and sees AI agents as a way to reduce the time needed to act on a trend.
