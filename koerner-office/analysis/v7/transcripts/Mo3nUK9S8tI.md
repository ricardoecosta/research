## Tactics and playbook steps

**Brand onboarding brief for AI** (product)
1. Upload all product photos
2. Tell Claude to act as creative director for the named brand and summarise it in one sentence
3. Have it extract key material details (e.g. smoke translucent, brushed steel, matte black)
4. Generate a colour palette from the product itself
> "I want you to be a creative director for Von, a premium hydration brand" — George McConnell (~1:54)

**Identity lock for a consistent AI model** (operations)
1. Describe the model briefly (age, skin, hair, accessories, outfit)
2. Name the model (e.g. Mara) so you can reference her later
3. Generate a 5-shot panel (front, three-quarters, side, smiling) and pick a master
4. Save the identity lock and paste it into every future prompt
> "I make sure that I name that model. This is so that I can always reference it back" — George McConnell (~7:33)

**Self-checking render loop** (operations)
1. Give Claude the correct logo/text reference
2. Ask it to audit every image for logo spelling and face match
3. Set pass thresholds (60-70%+)
4. Let it re-render failures until they pass
> "it will keep running this over and over and over until it hits that certain percentage of past ratings" — George McConnell (~13:22)

**Motion reference video** (product)
1. Film yourself on a phone doing the movement
2. Upload as performance reference
3. Have the locked model perform the same movement in a new setting
> "you can film yourself on your phone doing that entire movement" — George McConnell (~14:26)

**Name every product in the prompt** (operations)
1. List each garment/product to include in the context
2. Also name it explicitly in the prompt text
3. Double-check outputs before publishing
> "make sure that you're naming that specific product in there and not forgetting to either get the context as well as the prompt" — George McConnell (~20:59)

## Lessons

- *automation_ai*: Split roles: a reasoning model as 'brain' and a rendering tool as 'hands' turns prompts into finished deliverables.
- *offer_design*: Brand consistency (one face, fixed palette, consistent logo size) is what makes AI imagery look like a real brand.
- *automation_ai*: Build automatic QA into AI production: measurable pass thresholds and auto re-render.
- *offer_design*: Copy how big brands operate (3-5 recurring models) when producing AI content for clients.
- *operations*: Human review remains necessary; prompt omissions produce flawed assets.

## Warnings and mistakes

- AI models drift between shots unless you lock and name an identity.
- If you forget to name a product in the prompt, the render can omit it (the model appeared without the bra).
- Generated logos are often misspelled or distorted; audit before using.
- Video is partly promotional: Higgsfield connect link in the description.
