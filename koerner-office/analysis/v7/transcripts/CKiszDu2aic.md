## Tactics and playbook steps

**Multi-model niche selection** (validation)
1. Ask several models the same prompt for an underserved directory niche
2. Compare reasoning
3. Validate with Google Trends using the right buyer-intent term (e.g. 'estate cleanout', not 'estate sale')
> "What's an underserved local directory niche I could build and monetize?" — Chris Koerner (~2:14)

**AI-built directory in an hour** (product)
1. Prompt a model to compile 20 real businesses with name, category, phone, description in a table
2. Regenerate with other models; fact-check with a different model
3. Download CSV
4. Ask an agent to build a searchable directory with category/listing pages and Stripe featured upgrade
5. Provide Stripe secret/publishable keys
6. Deploy, add AI hero image, check admin panel
7. Scale to 1,000+ nationwide listings by telling the model how much work to do

**Niche vs geography rule** (product)
1. If the industry is very niche, go broad on geography
2. If geography is narrow, keep the industry broad
3. Go niche on both only with enough search demand
> "If the industry is very niche, then the geography should be more broad" — Chris Koerner (~14:07)

**Directory monetisation stack** (pricing)
1. Free listings for all
2. Charge for featured placement once they get leads
3. Banner ads (easiest, lowest value)
4. Capture consumer leads yourself and auction to listed businesses by email
> "Hey, I have this lead. It's in this neighborhood. We think it's worth this much. Who wants it?" — Chris Koerner (~19:23)

**Positioning by name** (product)
1. Name the business for the niche you want (Estate Cleanout Pros) to own it, accepting you lose adjacent work

## Lessons

- *niche_selection*: Directories are passive once built and may matter more as AI needs structured sources.
- *validation_testing*: Validate with the search term the buyer actually types.
- *offer_design*: Naming and positioning decide which customers call you.
- *finance_unit_economics*: Negative-COGS businesses get paid to acquire inventory.
- *automation_ai*: Use different models to cross-check each other's output.
- *automation_ai*: 'Token maxing' (using top models for everything) builds prompting skill.
- *niche_selection*: Consumer niches are easier to reach; B2B niches pay more.

## Warnings and mistakes

- Fact-check AI-compiled listings with a different model before publishing.
- Garbage in, garbage out: a typo in the prompt produced the wrong businesses.
- Models default to less work; specify scale (1,000+ listings).
- B2B directories earn more but it's harder to reach decision makers.
- Banner ads are the lowest-value use of directory traffic.
